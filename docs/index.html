01 · The shape

A database of claims, not a pile of documents

Three invariants keep the system honest and portable.

INVARIANT 01

Files are the source of truth

Everything lives as Markdown on disk, versioned by git. The vault survives any tool you stop using.

INVARIANT 02

The index is a cache

SQLite holds full-text rows and local embeddings. Delete it and rebuild; no knowledge is lost.

INVARIANT 03

The grammar is the API

Humans and agents write the same shape: an entity, atomic observations, typed relations.

02 · Architecture

One boundary between you and every agent

Basic Memory serves the vault over MCP. Clients come and go; the files remain.

03 · Quick start

Running in about ten minutes

Prerequisites: Python 3.12+, git, Obsidian, and Claude Code or another MCP client.

  1. Install Basic Memory One command with uv; it manages its own Python environment.
  2. Copy the vault template Clone the starter, or copy its folders into a vault you already have.
  3. Register the project project add indexes existing files and makes them searchable.
  4. Connect your agent Claude Code is one line; Codex, Gemini, and OpenCode configs are in the README. 
uv tool install basic-memory

git clone https://github.com/kasimlohar/second-brain-starter.git brain
cd brain

basic-memory project add brain "$PWD" --default
basic-memory status

claude mcp add basic-memory -s user -- basic-memory mcp

basic-memory doctor

On Windows, use "$env:USERPROFILE\brain" for the path. GUI clients need the absolute path to basic-memory.

04 · What you get

Conventions, not another app

A small set of files that makes existing tools behave like one system.

Plain Markdown

No database, plugin, or vendor holds your notes hostage. Any editor works.

Hybrid retrieval

Full-text plus local embeddings, fused and optionally reranked.

Agent-neutral

One MCP server serves Claude, Codex, Gemini, OpenCode, Cursor, and others.

Guarded writes

No blind overwrites; deletion is disabled by default and stays that way.

Five Claude commands

Recall, capture, triage, review, and backup as single slash commands.

Automatic backup

Obsidian Git commits and pushes to your private remote on a timer.

Local by default. Embeddings are computed on-device. Notes leave the machine only when you push to a remote you control.
