01 / The model

A database of claims, not a pile of documents

Three invariants keep the system honest, portable, and cheap to change.

01

Files are the source of truth

Everything lives as Markdown on disk, versioned by git. Stop using any tool in the stack and the vault survives.

02

The index is a cache

SQLite holds full-text rows and local embeddings. Delete it and rebuild; no knowledge is lost.

03

The grammar is the API

Humans and agents write the same shape: one entity, atomic observations, typed relations. One format, two writers.

02 / Architecture

One boundary between you and every agent

Basic Memory serves the vault over MCP. Clients come and go; the files remain.

Vault
The only authoritative store. Everything else can be rebuilt from it.
Basic Memory
Watches, indexes, searches, and exposes the tools every client calls.
Clients
Any MCP-capable agent. Configs for the major ones are in the README.
03 / Quick start

Running in about ten minutes

Prerequisites: Python 3.12+, git, Obsidian, and Claude Code or another MCP client.

  1. Install Basic MemoryOne command with uv; it manages its own Python environment.
  2. Create the vaultClone the starter, or copy its folders into a vault you already have.
  3. Register the projectproject add indexes existing files and makes them searchable.
  4. Connect your agentClaude Code is one line. Codex, Gemini, OpenCode, and Cursor configs are in the README.
~/brain bash 
# 1 · install the server
uv tool install basic-memory

# 2 · create the vault
git clone https://github.com/kasimlohar/second-brain-starter.git brain
cd brain

# 3 · register and index
basic-memory project add brain "$PWD" --default

# 4 · connect Claude Code
claude mcp add basic-memory -s user -- basic-memory mcp

# 5 · verify
basic-memory doctor

On Windows, use "$env:USERPROFILE\brain" for the path. GUI clients need the absolute path to basic-memory.
